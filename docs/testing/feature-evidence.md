A checklist item counts as **pressure-tested** only when all of these hold:

1. **Automated and passing:** a browser test names the item and passed in the last full run.
2. **Can fail:** one key assertion was broken on purpose and the test failed (`npm run test:e2e:mutation -- NN`, last recorded 2026-10-29T23:30:55.663Z).
3. **Repeats:** it passed 10 identical runs in a row (`evidence/stress.json`, last recorded 2026-10-23T03:17:23.865Z).

**Stale records:** 05-duplicates.spec.ts, 28-keyboard.spec.ts changed after their mutation check, so their "Can fail" is not counted until `npm run test:e2e:mutation` is run again for them.

Known bugs, items that cannot be automated here and items without a test keep a requirement from being pressure-tested. An item that backs two requirements counts in both.
